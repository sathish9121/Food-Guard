# 🍽️ Food Safety App

A Flutter-based Food Safety Management Application that enables citizens to report food safety violations, inspectors to conduct inspections, and administrators to manage restaurants and compliance records.

## Features

* Citizen food safety violation reporting
* Restaurant ratings and reviews
* Inspector dashboard and inspections
* AI-powered food safety analysis
* Real-time report tracking
* User authentication and role management
* Profile and settings management
* Supabase database integration

## Tech Stack

* Flutter
* Dart
* Supabase
* Provider
* SharedPreferences
* YOLOv8 (AI Analysis)

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/SASI-20041230/food_safety_app.git
cd food_safety_app
```

### OR Download ZIP

1. Click **Code → Download ZIP**
2. Extract the ZIP file
3. Open terminal inside the extracted folder

```bash
cd food_safety_app
```

### Install Dependencies

```bash
flutter pub get
```

### Check Flutter Environment

```bash
flutter doctor
```

### Run Application

```bash
flutter run
```

### Run on Chrome

```bash
flutter run -d chrome
```

### Clean Project

```bash
flutter clean
flutter pub get
```

### Build APK

```bash
flutter build apk --release
```

Generated APK:

```text
build/app/outputs/flutter-apk/app-release.apk
```
